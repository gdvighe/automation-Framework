🧪 E-Commerce Test Automation Framework
Built with Java · Selenium WebDriver · TestNG · Maven

This repository contains a structured and scalable test automation framework designed for practicing UI automation on an e-commerce website. It follows industry-standard design principles and provides an extendable foundation for functional, regression, and smoke testing.

🚀 Overview

The framework automates key user workflows on an e-commerce application, including:

User login

Product search

Adding items to the cart

Checking out

Validating UI components and interactions

It is designed to help in learning, experimenting, and building real-world automation practices, while also serving as a clean template for future projects.
Tech Stack
Component	Description
Java	Core programming language
Selenium WebDriver	Browser automation
TestNG	Test runner, annotations, reporting
Maven	Build and dependency management
Page Object Model (POM)	Scalable object repository
Extent Reports	For rich HTML reporting
🔧 Key Features
✔️ Page Object Model (POM)

Ensures a clean separation of UI structure and test scripts.

✔️ TestNG Integration

Provides annotations, parallel execution, grouping, and detailed reporting.

✔️ Maven-Driven Execution

Handles dependency management, build lifecycle, and command-line execution.

✔️ Cross-Browser Support

Configured to run in Chrome; easily extendable to Firefox, Edge, and others.

✔️ Centralized Configurations

Easily manage URLs, browser types, timeouts, and test data through properties files.

✔️ Reusable Utilities

Includes functions for waits, screenshots, logging, driver management, and more.

🖼 Reporting
Reports are automatically generated under the /test-output folder after each run.
